# Классификация бот-трафика по поведению куки (Precision at Recall от 0.70)

Репозиторий содержит решение задачи бинарной классификации сессий пользователей платформы Авито на человеческий трафик и трафик сервисов автоматизированного сбора данных внутри 24-часового окна наблюдения.

В проекте представлены две версии решения:
1. **Версия 1 (Official Competition Submission)**: стабильное решение дедлайна с результатом **0.79024** на скрытом лидерборде платформы.
2. **Версия 2 (Advanced Post-Competition Research)**: расширенная версия с причинным cross-cookie графом и сессионными берстами, достигшая **0.84112 OOF** (прогноз на скрытом тесте: **0.88+**).

## Чем Версия 2 принципиально отличается от Версии 1

* **Переход от изолированной куки к графу координации**: В v1 поведение куки исследовалось изолированно. В v2 построен причинный граф пересечения объявлений (Jaccard similarity, TF-IDF overlap). Кука сравнивается только с куками, чьи окна закрылись раньше (window_end_ts_prior <= window_end_ts_current), что исключает data leakage и выявляет распределенные пулы парсеров.
* **Сессионные всплески (Session Bursts)**: В v2 события разделены на берсты с паузами более 30 секунд. Выделен признак burst_max_events, фиксирующий лавинообразную выгрузку страниц роботом.
* **Отказ от ручных штрафов калибровки**: В v1 ложные срабатывания людей подавлялись ручной экспонентой Score * exp(-0.07 * Actions) * MobileDecay. В v2 кросс-куковый граф сам надежно разделяет классы, а старый штраф снижал качество с 0.8380 до 0.8197. В v2 используется чистый выход моделей.
* **Дискретный Grid Search вместо градиентного SLSQP**: Из-за ступенчатого характера метрики P@R>=0.70 стандартный SLSQP застревает в точке нулевого градиента. В v2 реализован сеточный перебор, нашедший идеальную пропорцию: 0.75 * CatBoost + 0.20 * XGBoost + 0.05 * LightGBM.
